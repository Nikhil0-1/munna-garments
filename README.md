# munna-garments

## Munna Readymade Garments — Retail POS & Inventory Management System
**Location:** Dhobwal Bazzar  
**Shop:** Munna Readymade Garments  

A complete, ultra-premium retail garment management system featuring Cloud Firestore, Firebase Auth, Realtime Database, POS counter billing, barcode scanning & printing, customer khata ledger, supplier management, daily expenses tracking, and public digital showroom.

### 🌟 Key Features
- **High-Speed POS Counter Billing**: Instant keyboard barcode scanner listener, variant & size selector, GST & discount computations, sequential invoices (MRG-2026-XXXX), and instant A5/Thermal bill printing.
- **Garment Inventory Management**: Support for categories, variants (sizes & colors), cost price, MRP, wholesale pricing, and 100% free web image links or canvas-compressed photos.
- **Barcodes & Hangtags**: Code 128 barcode generation and multi-tag hangtag printable sheets.
- **Stock Movements**: Inward Stock Entry, Stock Exit (damaged/sample/defective), and real-time audit ledger.
- **Customer & Supplier Khata**: Full debit/credit ledger, payment collections, and pending balance tracking.
- **Financials & Reports**: Daily expenses tracker, sales analytics, and multi-sheet Excel exports via SheetJS.
- **Public Digital Catalogue**: Customer showroom accessible via QR code for browsing products with direct WhatsApp inquiries.

### 🛠️ Tech Stack
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide Icons
- **Backend**: Node.js, Express, SQLite & Firebase
- **Cloud & Auth**: Google Firebase (Firestore, Auth, Realtime Database)
- **Utilities**: SheetJS (xlsx), jsbarcode, eact-hot-toast
